# urdf

## Arquivos

- `camera.xacro` — Define a câmera do robô e seu sensor no Gazebo Classic.
- `d_hospital.xacro` — Reúne os arquivos Xacro que compõem o modelo do robô.
- `d_hospital_core.xacro` — Define a estrutura, as rodas e as juntas do modelo principal.
- `gazebo_control.xacro` — Configura o plugin de tração diferencial do Gazebo Classic.
- `imu.xacro` — Define a IMU montada no robô e sua simulação no Gazebo Classic.
- `inertial_macros.xacro` — Fornece macros para calcular a inércia de formas usadas no modelo.
- `lidar.xacro` — Define o LiDAR e configura seu sensor de varredura no Gazebo Classic.
- `ros2_control.xacro` — Define as interfaces do ros2_control para os motores e sensores no robô real ou simulado.
