# construction_cone

## Subpastas

- [`materials/`](materials/README.md) — Recursos de aparência usados para renderizar o objeto.
- [`meshes/`](meshes/README.md) — Modelos 3D em COLLADA usados para representar as peças ou objetos.

## Arquivos

- `model-1_3.sdf` — Descreve o modelo do cone de obra no formato SDF 1.3.
- `model-1_4.sdf` — Descreve o modelo do cone de obra no formato SDF 1.4.
- `model.config` — Identifica o modelo do cone de obra e aponta para suas versões SDF.
- `model.sdf` — Descreve o modelo do cone de obra para o Gazebo.
