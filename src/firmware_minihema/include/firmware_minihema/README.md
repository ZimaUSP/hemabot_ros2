# firmware_minihema

## Arquivos

- `.motor_encoder.h.swo` — Arquivo temporário de recuperação criado pelo Vim durante a edição.
- `DEV_Config.h` — Declara tipos e macros usados para acessar a placa e seus periféricos.
- `KeyesDriver.h` — Declara as funções usadas para acionar o driver Keyes dos motores.
- `PinPlannerRasp.h` — Centraliza a identificação dos pinos do Raspberry Pi usados pelo firmware.
- `minihema_hardware.hpp` — Declara a interface ros2_control que liga o ROS 2 aos motores e encoders.
- `motor_encoder.h` — Declara as funções para ler e acompanhar os pulsos dos encoders.
- `wheel.hpp` — Declara a classe que guarda e calcula o estado de uma roda.
