# d_hospital_navigation2

## Subpastas

- [`config/`](config/README.md) — Arquivos YAML com parâmetros dos nós e componentes ROS 2 do pacote.
- [`d_hospital_navigation2/`](d_hospital_navigation2/README.md) — Diretório do módulo Python do pacote.
- [`launch/`](launch/README.md) — Arquivos Python que organizam quais nós do pacote sobem e com quais parâmetros.
- [`maps/`](maps/README.md) — Grades de ocupação, metadados e dados salvos do mapeamento.
- [`rviz/`](rviz/README.md) — Configurações de visualização salvas no RViz.
- [`scripts/`](scripts/README.md) — Nós e ferramentas Python do pacote.

## Arquivos

- `CMakeLists.txt` — Instala os recursos de navegação, mapas e o visualizador de trajetória.
- `package.xml` — Declara os metadados e as dependências do pacote ROS 2.
