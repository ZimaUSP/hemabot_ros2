# maps

## Arquivos

- `real_map3.pgm` — Guarda a imagem da grade de ocupação do ambiente real.
- `real_map3.yaml` — Indica a imagem `real_map3.pgm` e como posicioná-la e interpretá-la como mapa.
- `sim_map.data` — Guarda os dados serializados do mapeamento simulado associados ao grafo de poses.
- `sim_map.pgm` — Guarda a imagem da grade de ocupação do ambiente simulado.
- `sim_map.posegraph` — Guarda o grafo de poses que o SLAM Toolbox pode carregar para retomar o mapeamento.
- `sim_map.yaml` — Indica a imagem `sim_map.pgm` e como posicioná-la e interpretá-la como mapa.
